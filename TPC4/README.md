# Resumo
-  Desenvolvi uma aplicação baseada num menu, executado num ciclo "while" que termina apenas quando o utilizador seleciona a opção 0. A lista de trabalho é guardada numa variável interna, substituída sempre que se cria ou se lê uma nova lista (opções 1 e 2). Cada operação (soma, média, maior, menor, verificação de ordenação e procura) foi implementada numa função própria, recorrendo a ciclos "for" e sem utilizar funções predefinidas da linguagem. Adicioneia a resolução do caso da lista vazia, de modo a evitar erros de execução.
